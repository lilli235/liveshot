# 라이브샷 사용법

## 설치

1. [최신 릴리스](https://github.com/lilli235/liveshot/releases/latest)에서 ZIP을 다운로드하고 압축을 풉니다.
2. Chrome 주소창에 chrome://extensions 를 입력합니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 압축을 푼 폴더 중 manifest.json이 있는 폴더를 선택합니다.
5. 치지직 또는 유튜브 페이지를 새로고침합니다.

## 중계글 작성

1. 브라우저의 라이브샷 확장 아이콘을 눌러 사용할 디시인사이드 갤러리를 설정합니다.
2. 방송 페이지에서 **중계글 작성**을 누릅니다. **Alt+S** 단축키로도 열 수 있습니다.
3. 캡처 이미지와 제목·본문을 확인하고 필요하면 편집합니다.
4. **작성**을 눌러 디시인사이드 글쓰기 창을 엽니다.
5. 이미지 업로드가 끝나면 내용을 확인하고 직접 등록합니다. 업로드 중에는 글쓰기 창을 닫지 마세요.

작성창은 헤더를 드래그해 이동할 수 있습니다. 방송 링크 삽입 여부는 확장프로그램 설정의 **하이퍼링크 삽입**에서 변경합니다.

## 스크린샷·움짤 편집

- 캡처 이미지의 **편집**으로 스크린샷 편집창을 엽니다.
- **움짤 만들기**에서 사용할 구간과 출력 설정을 선택합니다.
- 움짤 만들기 창의 **편집**에서 효과를 조정한 뒤 최종 결과물을 만듭니다.
- 결과물은 **저장**으로 내려받을 수 있습니다.

## 임시저장

- **＋ 임시저장**으로 짤·움짤을 최대 10개까지 보관합니다.
- 썸네일을 클릭하면 작성창으로 불러옵니다.
- 썸네일을 드래그하면 첨부 순서를 바꿀 수 있고, 휠로 목록을 가로 이동할 수 있습니다.
- 썸네일의 **×**로 항목을 삭제합니다.
- 큰 움짤 미리보기를 클릭하면 재생·정지를 전환합니다.

## 업데이트

1. 필요한 이미지와 설정을 미리 보관합니다.
2. 새 버전 ZIP의 파일로 기존 설치 폴더를 갱신합니다.
3. chrome://extensions 에서 라이브샷의 새로고침 버튼을 누릅니다.
4. 열려 있던 작성창을 닫고 방송 페이지도 새로고침합니다.

확장프로그램을 삭제하거나 설치 폴더 경로를 바꾸면 기존 설정·임시저장이 유지되지 않을 수 있습니다.
