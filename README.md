# 라이브샷 — 라이브 캡처·중계글 작성

릴리스 버전: **1.0.0** · 설치 폴더: `liveshot`

기존 개발 버전의 기능을 유지하고 버전 번호를 새로 시작한 릴리스입니다.
기존 백업 ZIP은 변경하지 않습니다. 폴더 이동 전에 필요한 설정과 임시저장
이미지는 보관해 주세요. 확장 프로그램을 삭제하거나 다른 경로로 새로 설치하면
기존 확장의 저장 데이터가 자동으로 이전되지 않을 수 있습니다.

### 이번 정리

- 치지직·유튜브 이미지 복사 후 임시 Blob URL을 성공/실패 모두에서 해제합니다.
- 캡처 중단 시 영상 콜백과 보관 프레임을 함께 정리합니다.
- 숨겨진 탭에서는 헤더 UI 주기 검사를 생략하고 탭 복귀 시 갱신합니다.
- 화질, 프레임 설정, AI 모델 및 편집 기능은 유지합니다.

치지직 방송 화면을 캡처하고 디시인사이드 중계글 작성 화면에 제목, 이미지, 방송 링크와 본문을 자동으로 넣는 Chrome 확장프로그램입니다.

## 사용법

1. Chrome의 `chrome://extensions`에서 개발자 모드를 켭니다.
2. `압축해제된 확장 프로그램을 로드합니다`를 눌러 이 폴더를 선택합니다.
3. 브라우저 확장 아이콘을 눌러 갤러리와 상단 버튼 표시 여부를 설정합니다.
4. 치지직 상단의 `중계글 작성` 버튼을 누르고 내용을 확인한 뒤 `작은 등록 창 열기`를 누릅니다.

작성창 헤더를 드래그하면 위치를 옮길 수 있습니다. 다른 디시인사이드 갤러리의 등록·선택·삭제는 브라우저 확장 아이콘을 눌러 나타나는 설정창에서 할 수 있습니다. 단축키 `Alt+S`로도 작성창을 열 수 있습니다.

## 동작

- 브라우저 확장 아이콘은 설정 팝업을 엽니다.
- 치지직 상단 헤더의 툴킷 버튼은 중계글 작성창을 바로 엽니다.
- 작성창은 화면 우측에 표시되며 방송 화면을 블러 처리하지 않습니다.
- 캡처 이미지는 외부 호스팅을 거치지 않고 디시인사이드의 정식 이미지 첨부 입력란으로 전달됩니다.
- 방송 링크는 카드가 아닌 일반 하이퍼링크 형식으로 삽입됩니다.
- 디시 글쓰기 화면은 작은 팝업 창으로 열리고 제목·본문·이미지가 자동 준비됩니다.
- 사용자가 실제 디시 `등록` 버튼과 이어지는 확인창의 `확인`을 누르면 우측 작은 창이 닫히고 방송 창으로 복귀합니다.
- 등록 전후에 작은 창 하단 안내 배너가 다음 동작을 알려줍니다.
- YouTube 중계글 작성 기능은 유지됩니다.
- 메모, 채팅, 통나무 및 치지직 PIP 기능은 포함하지 않습니다.
